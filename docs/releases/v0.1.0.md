# ClipStack v0.1.0

ClipStack 的第一个版本：在菜单栏管理文本、图片和文件的剪贴板历史。

## 本版功能

- 自动保存剪贴板变化，提供分类和搜索，默认保留最近 500 条记录。
- 文本和文件点击只选中，使用独立“复制”按钮或 `⌘C` 复制。
- 图片网格预览，支持保持比例缩放和复制。
- `⌘⌃J` 在鼠标附近打开面板，可拖动边缘调整宽高。
- `⌘1` ～ `⌘4` 切换分类，`Return` 将所选记录粘贴到原应用。
- 历史数据保存在本机，跳过带有敏感剪贴板标记的内容。

## 下载与安装

要求 **Apple Silicon（M1 或更新芯片）、macOS 14 或更新版本**。

- 推荐下载 `ClipStack-0.1.0-macos-arm64.dmg`，打开后将 ClipStack 拖入 Applications。
- 也可下载同名 ZIP，解压后将 ClipStack.app 移到“应用程序”。
- 打开后通过菜单栏图标或 `⌘⌃J` 显示面板。
- 自动粘贴需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 ClipStack。

## 签名与已知限制

- 此版本使用 ad-hoc 签名，**没有 Developer ID 签名和 Apple 公证**。首次打开若被拦截，请在确认下载来源后，通过“系统设置 → 隐私与安全性 → 仍要打开”允许启动。
- 本次安装包仅支持 Apple Silicon，不支持 Intel Mac。
- 文件历史保存原文件路径；原文件移动或删除后，记录可能无法继续使用。
- 仓库目前为私有，下载需要仓库访问权限。

附件 `SHA256SUMS.txt` 可用于检查安装包完整性。GitHub 自动生成的 Source code 文件是源码，不是安装包。
