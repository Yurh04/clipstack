# ClipStack v0.2.0

本版聚焦于历史整理、安全删除和长内容查看。

## 新功能

- 文本记录支持“预览全文”，可滚动查看、选择文字和复制全文。
- 单条记录支持删除，删除后 10 秒内可撤销；退出期间到期的记录会在下次启动清理。
- 支持 `⌘⇧S` 收藏、`⌘⌫` 删除、`⌘Z` 撤销最近一次删除。
- 搜索支持内容、备注、OCR、标签，以及 `app:`、`type:`、`after:`、`tag:` 条件和双引号短语。
- 收藏支持标签，收藏页可以按标签和类型筛选。
- 文件或图片原路径失效时显示提示，复制、粘贴和预览前会检查路径。

## 下载与安装

要求 **Apple Silicon（M1 或更新芯片）、macOS 14 或更新版本**。

- 推荐下载 `ClipStack-0.2.0-macos-arm64.dmg`，打开后将 ClipStack 拖入 Applications。
- 也可下载同名 ZIP，解压后将 ClipStack.app 移到“应用程序”。
- 自动粘贴需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 ClipStack。

## 签名与限制

- 安装包使用 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证。
- 仅支持 Apple Silicon，不支持 Intel Mac。
- 文件历史保存原文件路径；原文件移动或删除后，记录无法继续使用。

## 发布验证

- 45 项单元测试通过。
- Release 构建、Info.plist 版本、代码签名、ZIP 完整性和 SHA-256 校验通过。
