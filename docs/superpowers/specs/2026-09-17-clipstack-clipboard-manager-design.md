# ClipStack — macOS 剪贴板增强工具 设计文档

> 日期：2026-09-17
> 状态：已通过 brainstorming 评审，待编写实现计划

## 1. 背景与目标

macOS 自带剪贴板存在三个痛点：

1. **调出慢**：必须 `⌘Space` 打开聚焦搜索，再点击右侧剪贴板按钮，两步操作。
2. **图片预览太小**：连续复制多张图片时，缩略图太小，粘贴时分不清哪张是哪张。
3. **无分类、垂直堆列**：文本、图片、文件全堆在一个列表里，难以查找。

**目标**：做一个轻量、常驻后台、全键盘驱动的剪贴板管理工具，一键弹出、分类清晰、图片可辨。

## 2. 技术栈

- **语言/框架**：Swift + SwiftUI（原生，启动快、内存小、系统集成最佳）
- **依赖库**（仅两个成熟开源库）：
  - `KeyboardShortcuts`（全局快捷键，支持用户自定义）
  - `GRDB.swift`（SQLite 封装，持久化存储）
- **架构参考**：开源项目 Maccy

## 3. 整体架构

分为 4 个职责单一、通过明确接口通信的模块：

```
ClipStack
├── ClipboardMonitor   监听系统剪贴板变化，抓取新内容
├── HistoryStore       持久化存储 + 查询/过滤/搜索
├── PasteService       全局快捷键 + 粘贴回原应用（系统集成）
└── UI (SwiftUI)       菜单栏图标 + 弹出面板
```

模块边界原则：UI 只调用 `HistoryStore` 的查询接口，不直接触碰底层存储；`PasteService` 负责一切系统级集成，与 UI 解耦。

## 4. 数据模型与存储

**存储方案**：SQLite（GRDB）存元数据 + 图片文件落盘。

- 图片存到 `~/Library/Application Support/ClipStack/images/`，数据库仅记录文件路径。
- 记录字段：

  | 字段 | 说明 |
  | --- | --- |
  | `id` | 主键 |
  | `type` | 类型：文本 / 图片 / 文件 |
  | `content` | 文本内容，或图片/文件的落盘路径 |
  | `sourceApp` | 来源应用名（用于展示） |
  | `createdAt` | 拷贝时间 |
  | `isSensitive` | 是否敏感内容（标记，正常不存密码） |

- **去重**：连续复制相同内容不新建记录，仅更新 `createdAt`。
- **容量控制**：默认保留最近 **500 条**，超出自动清理最旧记录（图片文件一并删除）。

## 5. 交互流程（全键盘 —— 解决"慢"的核心）

```
按快捷键（默认 ⌘⇧V）
  → 面板即刻弹出，光标自动落在搜索框
  → 直接打字过滤 / 或按 ↑↓ 选择
  → 回车 → 面板消失 → 自动粘贴到弹出前的前台应用
```

- **分类标签**（顶部）：全部 / 文本 / 图片 / 文件；数字键 `1~4` 或 `⌘←→` 快速切换。
- **自适应布局**：
  - 图片分类 → **大缩略图网格**（直接解决"分不清哪张"）。
  - 文本 / 文件分类 → **列表**（文字在方块里放不下，列表能看清内容与来源）。
  - "全部"默认视图 → 列表 + 中等缩略图，图片项适当放大。
- `Esc` 关闭；鼠标操作同样支持，但设计以键盘为先。

## 6. 系统集成与权限

- **全局快捷键**：`KeyboardShortcuts` 库，用户可自定义。
- **菜单栏图标**：SwiftUI `MenuBarExtra`，常驻菜单栏，点击也可弹出面板。
- **粘贴回原应用**：
  1. 记住弹出面板前的前台 App。
  2. 用户选中条目后，重新激活该 App。
  3. 用 `CGEvent` 模拟 `⌘V` 完成粘贴。
  - 需 **辅助功能权限（Accessibility）**，首次启动时引导用户授权。
- **密码安全**：自动跳过标记为 `org.nspasteboard.ConcealedType` / `concealed` / `transient` 的剪贴板内容（如 1Password），不落盘存储密码。

## 7. v1 范围（明确边界）

**做：**
- 剪贴板监听（文本 / 图片 / 文件）
- 历史持久化（SQLite + 图片落盘）
- 4 分类（全部 / 文本 / 图片 / 文件）
- 自适应布局（图片网格 / 文本列表）
- 全局快捷键（可自定义）
- 菜单栏图标
- 搜索过滤
- 全键盘操作
- 粘贴回原应用
- 跳过密码类敏感内容

**不做（留待后续）：**
- 跨设备云同步
- 收藏 / 置顶
- 富文本转纯文本
- 加密存储

## 8. 测试策略

- **可自动化（单元测试）**：`HistoryStore` 的增删查、去重、容量清理、分类过滤、搜索；敏感内容识别逻辑。
- **难自动化（手动验证）**：全局快捷键触发、粘贴回原应用、菜单栏弹窗、辅助功能权限流程 —— 靠手动运行验证，实现时如实标注"待手动验证"。

## 9. 开放项 / 默认值

- 工作名 **ClipStack**（可后续更改）。
- 容量默认 500 条（后续可做成设置项）。
- 默认快捷键 `⌘⇧V`（用户可改）。
- 分类暂不含"链接"独立分类（链接归入文本），如需后续再加。
